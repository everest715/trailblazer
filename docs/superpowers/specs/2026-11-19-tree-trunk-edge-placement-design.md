# 树木树干贴边定位设计

## 目标

树木生成在桌面边缘附近，树干根部仅保留轻微的向内位置扰动，避免因为树冠较宽而把树干推向桌面中央。

## 已确认行为

- 以树干根部作为树木的桌边定位参考。
- 根部向桌内随机偏移 `0–2 cm`，沿用 `inwardOffsetRange`。
- 树冠允许伸出桌面，不再要求完整树冠位于桌面区域内。
- 树木底部仍贴合 `area.SurfaceHeight`。
- 树木的随机朝向、缩放、间距和候选顺序保持不变。

## 约束与非目标

- 围墙仍使用完整可视模型进行桌面边界校验，行为不变。
- 不修改桌面识别、高度计算或虚拟桌面回退。
- 不为树木增加新的场景配置项。

## 方案比较

1. **继续按完整树冠内移**：能保证整棵树位于桌面内，但树干会离桌边较远，不符合需求。
2. **按树干根部贴边定位**：满足轻微扰动和树冠外伸要求；边界校验需要区分树木根部与完整可视模型。
3. **仅减小现有内移距离**：无法抵消半个树冠宽度造成的内移，不能解决根因。

采用方案 2。

## 实现要点

- 在 `PicoTableBoundaryObstacles` 中区分围墙与树木的定位策略。
- 围墙保留半个完整模型宽度的内移和完整模型边界校验。
- 树木不再附加半个树冠宽度；仅应用根部内移扰动，并使用树干根部的局部占用范围验证其位于桌面内。
- 添加树木根部距最近桌边不超过扰动上限的回归测试，同时保留围墙现有覆盖。
