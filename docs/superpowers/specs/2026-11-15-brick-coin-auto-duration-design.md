# 金币距离高度与自动时长设计

## 目标

- 将金币水平距离调整为 0.4 米、弧高调整为 0.3 米。
- 默认根据高度和重力自动计算飞行时间，不再要求手动同步调整。
- 保留手动时长选项。

## 已确认公式

起点和终点同高度时：

`duration = sqrt(8 * height / gravity)`

使用 `height = 0.3`、`gravity = 9.81`，自动时长约为 `0.4946` 秒。水平距离不改变飞行时间，只改变水平速度；0.4 米距离对应约 0.81 m/s。

## 设计

- `CollisionEffect.coinDropDistance = 0.4f`。
- `CollisionEffect.coinDropHeight = 0.3f`。
- 新增 `autoCoinDropDuration = true` 和 `coinDropGravity = 9.81f`。
- 自动模式使用上述公式；手动模式继续使用 `coinDropDuration`，其默认值改为 0.5 秒。
- 在 `MBrick Gate.prefab` 显式保存新配置，避免依赖反序列化默认值。
- 保持碰撞方向、Collider 禁用/恢复、30% 概率和其他行为不变。

## 方案比较

- 采用真实抛物线公式：与当前 `4 * height * t * (1 - t)` 轨迹一致，参数含义明确。
- 不按距离线性缩放时长：同高度物理抛物线的滞空时间由高度和重力决定，线性缩放没有物理依据。
- 不移除手动时长：保留特殊演出需要的手动覆盖能力。

## 边界与验证

- 高度为 0 时自动时长为 0，由现有 `CoinArcFlight` 钳制到最短 0.01 秒。
- 重力不大于 0 时使用 0.01 作为除数下限，避免除零和 NaN。
- 自动模式约 0.495 秒落地；手动模式使用配置时长。
- Prefab 参数正确，完整 PlayMode 回归通过。
